**Key Features:**
- 🔥 Streak tracking and badge rewards to keep crews motivated
- 📊 Monthly/annual analytics dashboards

**Tech Stack:** React • Python • FastAPI • MySQL • JWT
<br>*Currently under construction — still charting these waters!* 🧭

</div>

**Key Features (in progress):**

- 🍽️ Pre-orders linked directly to reservations
- 🔐 JWT authentication with role-based access across Customer, Restaurant Admin, and Platform Admin roles
- 🗄️ Normalised MySQL schema spanning ten-plus models, via SQLAlchemy ORM
- 🌐 RESTful FastAPI backend powering the whole voyage
